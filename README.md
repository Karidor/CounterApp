# CounterApp
Описание проекта

Counter App - это простое приложение-счётчик, разработанное с использованием Flutter.
Приложение позволяет пользователю изменять числовое значение с помощью кнопок.

Функционал
• Увеличение значения счётчика.
• Уменьшение значения счётчика.
• Сброс значения до нуля.

Используемые технологии
• Flutter - фреймворк для разработки приложений.
• Dart - язык программирования.

Цель проекта
Проект создан для знакомства с Flutter, изучения основ разработки мобильных приложений и получения практического опыта работы с Git и GitHub.

Планы по развитию
• Улучшение дизайна приложения.
• Добавление новых функций.
• Дальнейшее изучение Flutter и Dart.

Статус проекта
В разработке. Проект будет постепенно дополняться и улучшаться.
