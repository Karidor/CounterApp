# Counter App — Счётчик
Простое приложение-счётчик, созданное с помощью Flutter.

## О проекте

Это мой учебный проект для знакомства с Flutter и изучения основ разработки приложений.

## Функционал

- Увеличение значения счётчика
- Уменьшение значения счётчика
- Сброс значения до нуля

## Используемые технологии
- Flutter
- Dart
- Git
- GitHub

## Цель проекта
Изучить основы Flutter, научиться создавать простые приложения и получить первый опыт работы с Git и GitHub.

## Планы по развитию
- Реализовать счётчик
- Улучшить дизайн
- Добавить новые функции
