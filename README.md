Counter App — Счётчик
Простое приложение-счётчик, разработанное с использованием Flutter и Dart.
📌 О проекте
Этот проект создан для знакомства с Flutter и изучения основ разработки мобильных приложений.
⚙️ Функционал
- Увеличение значения счётчика.
- Уменьшение значения счётчика.
- Сброс значения до нуля.
🛠 Используемые технологии
- Flutter
- Dart
- Git
- GitHub
🎯 Цель проекта
Получить базовые навыки разработки приложений на Flutter, научиться работать с Git и GitHub, а также получить первый практический опыт программирования.
🚀 Планы по развитию
- Реализовать основные функции счётчика.
- Улучшить дизайн приложения.
- Добавить новые возможности.
- Продолжить изучение Flutter.
📍 Статус проекта
В разработке. Проект будет постепенно улучшаться и дополняться новыми функциями.
