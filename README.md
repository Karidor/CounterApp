# CounterApp
Counter App — Счётчик

Простое приложение-счётчик, созданное с помощью Flutter и Dart.

📌 О проекте

Counter App — мой первый учебный проект, предназначенный для знакомства с разработкой приложений на Flutter.

⚙️ Функционал

• ➕ Увеличение значения счётчика.
• ➖ Уменьшение значения счётчика.
• 🔄 Сброс значения до нуля.

🛠 Используемые технологии

• Flutter
• Dart
• Git и GitHub

🎯 Цель проекта

Изучить основы Flutter, научиться создавать простые приложения и получить практический опыт работы с Git и GitHub.
